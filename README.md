# Commonroom

A self-contained, responsive community feed prototype. Open `index.html` in a modern browser to use it.

## Working interactions

- Create and delete posts, and edit your own posts
- Reply to posts, and edit or delete your own replies
- Like and bookmark posts
- Search posts, replies, people, spaces, and tags
- Filter by space, saved posts, your posts, or people you follow
- Sort by newest or most loved
- Follow and unfollow suggested members
- Save posts and activity in browser `localStorage`, including after a reload

The sample members and conversations are starter content. This version stores data in the current browser only; a shared multi-user community needs a server and database.
